ECOTRACK - Règlement simplifié de collecte

La métropole organise la collecte des déchets ménagers sur douze zones. Les usagers doivent déposer leurs déchets dans les conteneurs correspondant au type de déchet. Les dépôts au sol, même à proximité d'un conteneur plein, sont interdits. Les cartons doivent être pliés avant dépôt. Les objets encombrants ne doivent pas être déposés dans les conteneurs : un rendez-vous doit être demandé auprès du service des encombrants.

Un conteneur est considéré critique à partir de 90 % de remplissage. Lorsqu'un conteneur critique est détecté, le gestionnaire peut déclencher une collecte prioritaire. Les tournées régulières privilégient les conteneurs dépassant 70 % de remplissage.

Les habitants doivent respecter les consignes affichées sur les conteneurs. Les produits dangereux, batteries, peintures et solvants sont orientés vers les déchèteries agréées.
